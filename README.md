# 🌿 Mohamed Khalif - Portfolio Website

This is a **bamboo-themed** personal portfolio website for **Mohamed Khalif**, a software developer based in Canada. 

## 📌 Features
- 🍃 **Elegant Bamboo Theme** – Soft green colors with a nature-inspired design.
- 🖼️ **Portfolio Gallery with Lightbox** – Clickable project images that enlarge in a modal.
- 📱 **Responsive Design** – Works on desktop and mobile devices.

## 🛠️ Tech Stack
- **HTML** – Structure of the website.
- **CSS** – Styling with a bamboo-inspired theme.
- **JavaScript** – Lightbox modal functionality.
